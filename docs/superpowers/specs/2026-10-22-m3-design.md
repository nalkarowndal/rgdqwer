# M3 Image to Prompt 설계

마스터 요구사항 §9/M3: 업로드 → 로컬 Florence-2 캡션/OCR 및 WD14 태그 → 필드 수정/잠금 → 모델별 프롬프트 → 이미지 생성. 원본 프롬프트 복원을 주장하지 않는다. M2 위의 별도 기능 브랜치와 초안 PR로 진행한다.

## 구조와 선택

기존 독립 Python Worker를 확장한다. ComfyUI custom node 의존은 기존 환경을 변경하고, 외부 VLM API는 로컬 원칙에 맞지 않으므로 사용하지 않는다. UI는 Node 인증 API를 통해 Worker를 호출한다. 업로드 파일은 디스크에 저장하지 않는다. PNG/JPEG/WebP 단일 프레임, 5 MiB/16 MP/변당 8192 제한, 실제 디코딩 및 EXIF 방향/투명 배경 처리를 한다. 분석 요청 JSON은 7 MiB로 제한한다.

Worker 실행 시 로컬 모델 폴더를 지정한다. Florence는 native Transformers의 Florence2ForConditionalGeneration + AutoProcessor, safetensors/local_files_only/trust_remote_code=False로 캡션과 OCR을 수행한다. 변환된 florence-community 체크포인트를 요구한다. WD14는 model.onnx + selected_tags.csv를 CPUExecutionProvider로 실행한다. 공식 demo와 같은 흰 배경/정사각 padding/bicubic/BGR float32 NHWC 전처리. 일반 태그 0.35, 캐릭터 0.85, rating은 프롬프트에서 제외. 최대 100개 반환. 점수는 보정된 확률이 아니다.

기본 CPU만 제공: RTX 2060 SUPER에서 미검증 CUDA/BF16 경로를 묵시적으로 활성화하지 않는다. 모델은 순차 실행하고 호출 후 해제한다. 한 Worker에서 동시 분석 1개, 추가 요청 409. Node 300초 제한, UI 310초 제한. 시간 초과는 추론 중단을 뜻하지 않으며 Worker 상태에서 진행 여부 확인/종료 후 재시도한다. 추론 성공/호환성은 파일 발견과 구별한다. 모델 자동 다운로드와 원격 코드 실행은 없다.

Node가 데이터 디렉터리에 worker.token을 최초 생성(32 random bytes, POSIX0600)한다. Worker는 실행 시 이 파일의 경로를 받아 같은 토큰으로 /analysis와 /analysis/status를 인증한다. 경로는 UI에 안내하되 토큰은 반환하지 않는다. Worker는 loopback CLI 바인딩, Host 검증, Origin 요청 거부, streaming body limit를 적용한다. /health는 진단만 공개한다. Node는 리다이렉트를 거부하고 응답 크기/스키마를 검사한다.

## 편집과 보존

원시 캡션/OCR/태그와 출처를 보존한다. 알려진 일반 태그만 보수적으로 10개 필드로 분류하고 미분류 태그는 별도 편집란에 둔다. 캡션을 전체 설명으로 사용하며 의미 분해를 모델 기능처럼 꾸미지 않는다. 비어 있는 필드는 미확인으로 표시한다. 캡션에는 수치 신뢰도를 만들지 않는다. 모든 편집란은 잠금 가능, 재분석 시 잠긴 값 및 분석 도중 수정된 값 유지. 파일 변경도 같은 규칙을 적용하여 캐릭터/의상 고정이 가능하다.

분석 페이지의 초안/이미지는 앱 내 이동에 유지, 새로고침 시 사라짐을 안내한다. 프로필별 tags/natural 형식으로 생성하며 OCR 포함은 기본 해제. 최종 문자열 8000자 제한. 보내기는 명시적 버튼, 자동 생성 없음. M2 문서/프리셋/기록과 이미지 스튜디오를 재사용한다. 영상/Krea는 해당 단계에서 연결한다.

## 검증과 한계

보안/입력 검증/전처리/잠금 경합/모델 미설치/모델 출력 불일치 단위 테스트, Node↔Worker 계약, 업로드→수정→재분석→ComfyUI 요청 E2E. 테스트 분석 결과는 명시적 fixture. 실제 Florence/WD14 가중치와 Windows/RTX2060SUPER가 없으므로 실기와 품질 게이트는 열린 상태. Linux/Windows CI와 독립 최종 리뷰 후 초안 PR을 생성한다.
