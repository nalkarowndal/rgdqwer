# 단계별 개발 계획

| 단계 | 산출물 | 다음 단계 진입 조건 | 현재 |
|---|---|---|---|
| M0 | Electron/React/Node/Worker/SQLite/API/QA | 앱 실행, 실제 ComfyUI 연결, 빌드·기본 테스트 | 기반 구현, 실기 게이트 남음 |
| M1 | SD 프로필, T2I, 설정·결과 저장, 진행률/오류 | 실제 이미지 생성·저장 및 취소/실패/재시도 | 기본 T2I 구현·모의 QA, 실기 게이트 남음 |
| M2 | 3개 입력 모드, 템플릿/어댑터/프리셋/기록 | 한국어 입력을 지원 범위 안에서 변환해 실제 생성 | 이미지 3모드·규칙 변환·저장 구현, 실기 게이트 남음 |
| M3 | VLM/태거, 필드 편집/잠금, 생성 연계 | 업로드→분석→수정→실제 생성 | CPU 어댑터·편집/잠금·연계 구현, 실기 게이트 남음 |
| M4 | Krea RAW/Turbo 프로필/LoRA/호환성 | 공식 워크플로 실행 또는 검증된 불가 원인 안내 | UI/그래프/진단/LoRA/연계 구현·모의 QA, 실기 게이트 남음 |
| M5 | 영상 T2V/I2V/기본 V2V/FFmpeg | 실제 경량 모델 생성/변환 및 MP4 재생 | 구현·실제 FFmpeg 변환/재생 통과, Wan 실기 게이트 남음 |
| M6 | 음성 프로필/TTS/VC/RVC, 후속 학습 | 실제 TTS와 VC 각각 검증 | 연동·프로필·녹음·출력 구현, 실제 모델 추론 통과 보류 |
| M7 | 모델 설치/제거/의존성/라이브러리/VRAM | 모델 관리부터 생성까지 충돌 없는 통합 흐름 | 구현·Windows/Linux CI 통과 / 실제 모델·Windows GPU 게이트 보류 |
| M8 | 장시간 QA/메모리/설치 프로그램 | 처음 설치한 Windows에서 주요 흐름과 문서 확인 | 구현·Windows/Linux CI 및 설치/재설치/제거 통과 / 실제 모델·클린 Windows·서명 게이트 보류 |

각 단계는 자동 테스트와 모델 실기를 분리해 기록한다.
환경 때문에 통과 조건을 실행하지 못하면 '완료'가 아니라 '검증 보류'로 남긴다.
현재 환경의 모의 API 테스트만으로 M1 실제 생성 개발 완료를 선언하지 않는다.

M0 후속: 사용자 Windows에서 ComfyUI 연결/실제 장치 표시, 앱 종료/재시작 및 설정 복구.
M1은 SD1.5/SDXL/Illustrious 기본 그래프를 구현했다. 실제 모델은 계열별 검증하며 Anima는 별도 그래프 후속 작업이다.
RVC 학습은 M6 기본 TTS/VC 안정화 이후 별도 작업 묶음으로 편성한다.

제외: 다중 캐릭터 영역 LoRA, 실시간 마이크 VC, 립싱크, 자동 영상 편집, 클라우드 GPU,
모바일/협업/커뮤니티 및 요청하지 않은 AI 기능.

M5: Wan 그래프·전용 UI·MP4 업로드/검증·FFmpeg 변환/보간/프레임 추출·재생/다운로드/재사용 구현. 합성 클립 실제 CPU 실행 검증, Wan/GPU 실기 게이트 유지.

M6: 음성 프로필·권한 기록·독립 Chatterbox/RVC 프로세스·WAV/MP3·녹음·비교 구현. 실제 모델 추론/Windows 마이크/GPU 게이트 유지.
