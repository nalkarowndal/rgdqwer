# 영상 시스템

현재: 카테고리와 M5 제공 예정 안내. 생성/FFmpeg 호출은 미구현.

M5에서 Wan 2.2 TI2V 5B 등 후보의 공식 워크플로, 라이선스, CPU offload 및 시스템 RAM
조건을 확인한다. RTX 2060 SUPER에서 낮은 해상도/짧은 프레임부터 실측한다.
5B 또는 '8GB 가능' 문구만으로 정상 동작을 보장하지 않는다.

T2V, I2V, 기본 V2V, 프레임 추출/보간/업스케일을 각각 capability로 분리한다.
영상 프롬프트에는 동작·속도·카메라·장면 변화와 시작/종료 상태를 포함한다.
I2V는 원본 외형 보존과 동작 설명을 구분한다.

FFmpeg는 shell 문자열 없이 인자 배열로 호출하고, 입력 파일·출력 경로·코덱을 검증한다.
출력 MP4 재생 가능 여부와 프레임 수/FPS/길이를 검사한다.
GPU 단일 작업 정책, OOM 복구 및 사용자 설정 수정 후 재시도를 검증해야 M5 통과다.
