# 프롬프트 시스템 — M2

프롬프트 스튜디오와 이미지 스튜디오가 같은 로컬 편집기를 사용한다.
지원 대상은 현재 실행 그래프가 있는 SD1.5, SDXL, Illustrious다.
영상·음성·Krea 입력은 각 실행 단계에서 추가하며, Image to Prompt는 M3 범위다.

## 입력과 변환

- **간편(기본):** 한국어 키워드를 쉼표 또는 줄바꿈으로 구분한다. 예: `고양이, 숲, 부드러운 조명`.
  추천 키워드·검색 자동완성 버튼·예시를 제공한다.
- **상세:** 주체, 외모, 의상, 표정, 자세/동작, 배경, 화풍, 구도, 조명, 색감을 입력한다.
  키워드는 마지막으로 선택한 상세 항목에 추가한다.
- **전문가:** 최종 positive/negative를 직접 편집한다. 공백, 가중치, 이스케이프를 그대로 전달한다.
  LoRA 파일·강도·활성화는 이미지 스튜디오에서 설정한다. 샘플러는 이미지 프로필별 고정값을 사용한다.

`src/prompt.ts`의 정확한 키워드 사전으로만 변환한다. `고양이 없는 숲` 같은 모르는 구절을
부분 번역하지 않으며 원문과 미지원 안내를 보존한다. 완전한 한국어 번역 또는 LLM 생성이 아니다.
SD1.5/Illustrious는 태그형, SDXL은 항목을 연결하는 문장형 템플릿이 기본이며 사용자가 바꿀 수 있다.
Negative 추천은 선택 사항이다. 실제 체크포인트별 최적 프롬프트라는 보장은 없다.

## 수정 보존

어떤 모드에서도 최종 positive/negative를 직접 수정할 수 있다. 수정한 값은 원문, 모드,
프로필, 카테고리 이동으로 덮어쓰지 않는다. 빈 negative도 명시적인 수정값이다.
'수정값 지우고 추천 재적용'만 두 최종 수정값을 초기화하고 현재 원문에서 다시 조합한다.
프리셋/기록 불러오기와 이미지 스튜디오로 보내기는 버튼 설명대로 해당 초안을 교체한다.
복사 권한 오류는 수동 복사 안내로 처리한다.

## 저장과 생성 연결

PromptDocument v1은 모드·스타일·원문·상세 항목·negative 옵션·수동 결과를 보관한다.
프리셋은 최대100개, 프롬프트 기록은 최근100개. 현재는 새 이름으로 저장/불러오기/삭제를 지원한다.
삭제는 프롬프트 기록만 지우며 이미지 Job/PNG를 지우지 않는다.
브라우저/앱 새로 열기 전에 프리셋이나 기록으로 저장해야 한다. 미저장 초안은 페이지 이동 동안만 보존한다.

이미지 생성은 최종 positive/negative와 optional promptDocument를 함께 전송한다.
서버는 문서에서 계산한 결과와 실제 전송 문자열이 일치하는지 확인한다.
최초 Job와 프롬프트 기록을 같은 DB 쓰기로 저장하므로 진행률 갱신마다 중복 기록하지 않는다.
실패한 생성 요청의 원문도 기록에 남는다. 기존 M1 작업은 전문가 문서로 정확히 재사용한다.
저장된 기록을 불러올 때는 당시 최종 결과를 고정해 규칙 변경으로 결과가 바뀌지 않게 한다.

## 후속

선택형 로컬 LLM은 compilePrompt의 문서/결과 경계를 확장할 수 있게 분리했다.
현재 모델 다운로드, 외부 번역 서비스, 로컬 LLM 실행 endpoint는 없다.
Krea Prompt Enhancer와 앱 확장기의 중복 실행 정책은 Krea 실행 adapter에서 추가한다.
M3는 분석 결과를 원본 프롬프트 복원이라고 표현하지 않고 수정/잠금 가능한 재구성으로 제공한다.

자동 QA는 한국어→문자열→실제 HTTP 모의 ComfyUI graph→PNG까지 검증했다.
실제 모델의 한국어/영어 출력 품질과 GPU 실행은 별도 실기 게이트다.
