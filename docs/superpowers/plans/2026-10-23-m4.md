# M4 Krea Studio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 로컬 Krea RAW/Turbo의 진단·편집·생성·저장·재사용.
**Architecture:** 공유 GenerationManager와 분리된 Krea 계약/노드 어댑터, 전용 React 화면.
**Tech Stack:** 기존 TS/React/Fastify/sql.js/ComfyUI; 의존성 추가 없음.
**Spec:** docs/superpowers/specs/2026-10-23-m4-design.md

## Global Constraints
로컬 loopback+Bearer만. 자동 설치/전역 interrupt/중복 제출 없음. Turbo8/CFG1,RAW52/CFG4.5. 배치1. RAW<=1024,Turbo<=2048. 실제 GPU 성공을 가장하지 않음.

## Review Focus
- 모델/노드 목록 변경 후 제출: stale UI로 잘못된 모델 제출 금지.
- RAW CFG와 shift: standalone와 Comfy 의미 차이 반영.
- 엔진 확장+LoRA: 확장 한 번, 트리거 뒤에 결합, 사용자 편집 보존.
- SD/Krea 동시 작업 및 기록: 공유 잠금, 올바른 화면 복원.
- 미연결/CPU/8GB/알 수 없는 메모리: 구체적 경고, 지원 확정 표현 금지.
