# rgdqwer M0 설계

사용자 제공 마스터 프롬프트를 전체 제품 명세로 사용한다. 이번 구현 단위는 M0다.
빈 원격 저장소를 확인했으며 기존 이름 rgdqwer를 유지한다. 기존 코드/설정/테스트는 없다.

## 목표와 경계

Windows 10/11에서 사용자가 자신의 ComfyUI에 연결하고, 상태와 장치/메모리를 확인하고,
로컬 설정을 재시작 후에도 보존할 수 있는 Electron 앱을 만든다.
React 웹 실행 환경에서도 동일 Node 제어 API를 사용한다.
Python 보조 Worker는 독립 venv에서 건강 상태와 하드웨어 진단을 제공한다.
모델 다운로드, GPU 생성, 음성 복제, 자동 ComfyUI 설치/실행은 M0에 포함하지 않는다.
미구현 카테고리는 개발 단계와 실제 사용 가능 여부를 표시한다.

## 설계 선택

1. **선택: Electron + React + Fastify + SQLite(sql.js) + 독립 FastAPI.**
   사용자의 권장 구조를 따르며 SQLite WASM으로 Electron/Node 네이티브 ABI 재빌드 문제를 피한다.
   데이터는 한 Node 프로세스만 소유하며 동기식 임시 파일 저장 후 rename한다.
   M0의 소규모 메타데이터에 적합하다. 작업 기록이 커지면 native SQLite/WAL 전환을 재검토한다.
2. Electron 안에서만 IPC로 모든 기능 제공: 간단하지만 브라우저 QA 및 Worker 통합 계약 재사용이 불리하다.
3. Comfy API v2 + API Proxy: 버전 계약이 유리하지만 별도 프로세스가 필요하다.
   현재는 모델/노드 조회와 기존 설치 연결이 우선이므로 raw Server API 어댑터를 선택한다.

## 구성과 계약

- `server/store.ts`: 설정, 스키마 버전, jobs/artifacts 테이블. 설정 변경은 검증 후 원자적으로 영속화.
- `server/comfy.ts`: 127.0.0.1 HTTP 엔드포인트 검증, 시간제한, redirect 금지, JSON 구조 검사.
  `/system_stats`, `/object_info/CheckpointLoaderSimple` 조회. 생성은 M1.
- `server/app.ts`: loopback 전용 Fastify, 세션 토큰, Host/Origin 검사, 제한된 API.
- `server/index.ts`: 독립 Node 실행과 종료 처리.
- `desktop/main.ts`: 같은 Node 서버를 기동하고 해당 origin만 BrowserWindow에 로드.
  Node integration 끄기, sandbox/context isolation 켜기, 외부 탐색/새 창/권한 요청 거부.
- `src/`: 한국어 대시보드, 연결 설정, 이미지 모델 조회, 단계별 사용 가능 상태.
- `worker/app.py`: `/health`, `nvidia-smi`가 없으면 unknown/unavailable. PyTorch/CUDA 추론 성공으로 주장하지 않음.

API 상태는 connected/disconnected/error, 측정하지 않은 VRAM은 null이다.
설정 기본값은 ComfyUI `http://127.0.0.1:8188`, Worker `http://127.0.0.1:8189`.
M0는 같은 PC 연결만 허용한다. 사용자 지정 포트 가능, 원격 호스트와 URL 자격증명/경로 금지.
ComfyUI 설치·모델 경로는 참조 설정만 저장하며 자동으로 폴더를 이동하거나 엔진에 적용하지 않는다.
UI에서 이 경계를 명확히 표시한다.

## UX

밝은 중성 바탕, 짙은 사이드바, 청록 강조색. GPU 상태를 만들어 표시하지 않는다.
홈에서 연결 상태/지원 범위/시작 절차를 제공하고 설정에서 URL을 저장·검사한다.
고급 옵션은 접을 수 있다. 모바일 폭에서는 내비게이션과 카드가 한 열로 흐른다.
키보드 포커스, label, 상태 알림, 오류의 해결 방법을 제공한다.

## 검증과 완료 조건

- Vitest: 영속성, 잘못된 설정의 무변경, 토큰/Origin/Host 차단, 실제 HTTP Comfy 모의 서버,
  응답 손상/지연/연결 실패/체크포인트 없음 처리.
- pytest: Worker 상태와 GPU 미탑재/응답 오류 처리.
- Playwright: 실제 Node+React 앱에서 설정 저장/재진입/미연결 표시/카테고리 이동/반응형.
- TypeScript, ESLint, 프로덕션 빌드.
- Electron 구동과 Windows 실기 검증은 환경에서 가능 여부를 별도로 기록.
- 실제 ComfyUI 연결 및 생성은 설치된 엔진과 모델이 있어야 검증 가능. 모의 API 통과로 대신하지 않는다.
