# M0 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 실행 가능한 로컬 스튜디오 기반과 재현 가능한 M0 QA 제공.
**Architecture:** Electron이 loopback Node 서버와 SQLite를 소유. React는 인증된 HTTP API 사용.
ComfyUI와 Python Worker는 별도 실행 환경으로 연결.
**Tech Stack:** React 19, TypeScript 5, Vite 7, Electron 43, Fastify 5, sql.js, FastAPI.
**Spec:** `docs/superpowers/specs/2026-10-20-m0-design.md`

## Global Constraints

- 이름 rgdqwer 유지. Windows 10/11, NVIDIA RTX 2060 SUPER 8GB 대상.
- localhost 서비스만 연결. 모델 자동 다운로드/실행 없음.
- 생성 미구현 상태 명시. 모의/실기 검증 분리.
- 사용자 18절의 실행 지시에 따라 문서 작성 후 M0까지 진행.

## Review Focus

1. 외부 웹 페이지의 localhost 요청: 토큰과 Origin/Host 검사로 차단.
2. 손상되거나 ComfyUI가 아닌 응답: 연결 성공으로 오인하지 않음.
3. 저장 실패 및 재시작: 변경 전 설정 보존, SQLite 무결성 유지.
4. GPU 없음/드라이버만 존재: CUDA 실행 가능 상태로 과장하지 않음.
5. 설정 저장과 연결 확인 중 연속 클릭: 중복 요청 및 이전 응답 표시 방지.

## Task 1: 제어 API와 영속성

Files: `server/{app,store,comfy,index}.ts`, `src/contracts.ts`, `tests/server.test.ts`,
`package.json`, `tsconfig*.json`.
Interfaces: `createApp({dataDir,uiDir?}) -> FastifyInstance`;
`openStore(dataDir) -> {getSettings,saveSettings,listJobs,close}`;
`probeComfy(url,timeoutMs?) -> EngineStatus`.

- [ ] 영속성/입력 검증/인증/모의 Comfy API 테스트를 먼저 작성하고 실패 확인.
- [ ] 최소 구현 후 `npm test` 실행. Expected: 전체 API 테스트 통과.
- [ ] 백엔드와 SQLite 기반 커밋.

## Task 2: 독립 Python Worker

Files: `worker/app.py`, `worker/requirements*.txt`, `worker/tests/test_app.py`.
Interface: GET `/health` -> `{status,engine,capabilities,hardware}`.

- [ ] GPU 없음, 잘못된 nvidia-smi 결과, 정상 파싱 테스트 실패 확인.
- [ ] GPU 검출과 진단만 구현. 생성 capabilities 빈 배열.
- [ ] `python -m pytest worker/tests` 실행. Expected: 전체 Worker 테스트 통과.

## Task 3: Electron·React 통합

Files: `desktop/main.ts`, `src/{App,main}.tsx`, `src/styles.css`, `vite.config.ts`,
`e2e/studio.spec.ts`, `playwright.config.ts`.
Interface: `/api/session` bootstrap 후 bearer 인증, M0 서비스 계약 재사용.

- [ ] UI 테스트: 대시보드, 설정 영속성, 연결 실패 도움말, 미구현 생성 버튼 비활성화.
- [ ] 실제 Node API에 연결한 React UI와 Electron 보안 shell 구현.
- [ ] `npm run check`, `npm run build`, `npm run test:e2e`. Expected: 모두 통과.
- [ ] 실제 화면 캡처 검수, Electron 실행 가능 여부 기록.
