# M7 models, extensions and library

Implements REQUIREMENTS.md §§10–12 and M7. Model installation/import/removal, dependency and path management, optional third-party assets, searchable/favorite/comparable generation library, and idle GPU memory release integrate with the existing generation lock.

## Approach and implementer decisions

Use an app-owned asset store with explicit user-selected imports/downloads, managed metadata and a generated ComfyUI path configuration. A remote ComfyUI-Manager control plane would add version/permission dependencies; directly taking ownership of arbitrary existing model folders risks modifying user files. Existing files discovered during scans remain read-only; only installed records may be removed, with a matching hash and explicit confirmation.

Managed root defaults to app-data/models and can be changed to an absolute local folder. Existing assets retain their recorded roots; changing the active root never moves/deletes files. A generated YAML maps all managed Comfy model roots; user starts ComfyUI with --extra-model-paths-config or incorporates the configuration and restarts. Do not overwrite existing Comfy config. Analysis and voice assets remain independently configured using displayed local paths and existing worker setup. Import individual files into named bundles to support multi-file models.

Metadata: stable id, display name, kind (checkpoint/lora/vae/text_encoder/analysis/video/voice), family, filename/bundle, source URL/revision, bytes, SHA256, license, required asset IDs and nodes, estimated VRAM (explicitly unmeasured). Missing metadata remains unknown. Download requires HTTPS public source, exact size and SHA256, confirmed license/rights; redirects undergo the same destination policy. Validate DNS, pin the resolved public address for TLS, reject loopback/private/link-local/mapped destinations, credentials and non-443 ports. Preserve proxy policy in managed environments; downloads through configured HTTPS proxy must not bypass its restrictions. Imports stream from an explicitly selected absolute regular file; no source execution. Installation uses bounded streaming, disk-space preflight, temporary files and no-overwrite commit. Max file 64GiB; max 10000 inventory entries and depth 8. Cancel/timeout/failure removes partial data. Recover interrupted tasks as failed, never auto-resubmit.

Custom nodes: GitHub HTTPS repository + exact 40-hex commit, explicit code-risk acknowledgement. Fetch into a staging folder with isolated Git configuration, no hooks/filters/submodules, no Python/pip execution. Inspect static dependency/license files and reject symlinks/path escapes. Activation is a separate acknowledged action that copies reviewed code into an app-managed custom_nodes root referenced by the generated YAML; restart ComfyUI explicitly. Deactivation/removal affects only app-owned, unmodified trees. Installation diagnostics report that dependencies must be installed in the correct ComfyUI environment. Max pack 256MiB/10000 files; no automatic dependency installation or engine restart.

Every model/path/node mutation and /free request acquires the shared maintenance lock, blocks generation, and checks an accessible Comfy queue before modifying files. Generation blocks maintenance and vice versa. Active or unresolved work blocks mutations; historical model references require explicit removal acknowledgement rather than deleting histories. Concurrent processes outside this app remain outside the lock.

Library: query all persisted jobs with pagination, text/kind/favorite filters, editable title, favorites, up to four result cards for side-by-side comparison, existing download/reuse actions. Existing histories remain intact on DB v6 migration. Memory action only when local and Comfy queues are idle, POST /free with unload_models/free_memory; report request accepted, never claim synchronous VRAM release. Actual free memory comes from engine status. Existing batch/resolution/frame/chunk safeguards and no-auto-retry OOM behavior remain.

Acceptance: real streamed local import/hash/delete; bounded download transport fixtures plus SSRF policy tests; staged node source inspection without execution; model-to-generation handoff using a clearly simulated Comfy engine; real library and browser flows; Windows/Linux CI. True model inference, Windows desktop devices, real GPU behavior and remote large downloads are separate target-environment gates. Network limitations are reported without bypassing policy.
