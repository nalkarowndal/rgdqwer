# UI/UX

현재: 한국어 대시보드·설정·모델 목록·이미지 생성 폼·PNG 결과/작업 기록, 10개 카테고리 이동.
짙은 좌측 내비게이션, 밝은 작업 영역, 청록 강조색으로 상태와 다음 행동을 구분한다.
연결 전 메모리를 0GB 또는 가짜 장치로 표시하지 않고 '확인 전'으로 표시한다.
아직 실행할 수 없는 카테고리는 후속 단계 계획과 비활성 생성 버튼을 보여준다.

설정은 서버 주소를 저장한 뒤 연결 검사한다. '저장된 주소 연결 검사'는 아직 저장하지 않은
입력값을 쓰지 않는다. 저장 버튼을 잠가 중복 요청을 방지한다.
연결 조회는 15초 주기이고 이전 요청이 늦게 끝나도 최신 상태를 덮어쓰지 않는다.

고급 경로/저VRAM 참조 설정은 details로 접는다. label, 오류 role=alert,
상태 role=status, aria-current, 키보드 포커스, reduced-motion을 제공한다.
760px 이하에서 상단 가로 내비게이션과 좁은 카드 레이아웃으로 바뀐다.

예정: 결과 비교, 모달, 업로드, 재생, 모든 실제
생성 옵션의 한국어 설명/툴팁. 미지원 파라미터는 숨기거나 비활성화한다.

이미지 폼은 프로필/체크포인트/positive/negative를 노출하고 크기·스텝·CFG·시드는 상세 설정으로 접는다.
샘플러 진행률과 전체 시간 비율을 구분한다. 미확인 작업은 추적 재개, 실패 작업은 설정 재사용으로 복구한다.
작업 기록은 최근 20개를 표시하며 인증된 PNG blob을 화면 이탈 시 해제한다.

M2: 이미지/프롬프트 스튜디오의 공통 3모드 편집기, 키워드 검색/추천, 출력 형식/negative 추천,
수동 결과 보존, 복사와 프리셋/기록 저장·불러오기·삭제, 생성으로 보내기를 제공한다.

## M3 Image to Prompt

업로드/모델 상태/준비 안내와 필드 편집을 나란히 배치하고 좁은 화면은 단일 열로 표시한다.
캡션·10개 항목·미분류 태그·OCR의 잠금 및 수정, 원문 점수 상세, 캡션/OCR 포함 선택, 생성 프로필과 명시적 적용 버튼을 제공한다.
