# M3 최종 리뷰와 결정 기록

기준: M2 `6797ad3` → M3 `76e8406`, 수정 커밋 `782cc13`.
독립 리뷰: fresh-context gpt-6-astra (`m3_review`). 주요 결함 1개, Critical/유예 Minor 없음.

## 수정

- 허용 크기(약4.2MiB)의 실제 PNG가 Node base64 정규식의 반복 그룹으로 stack overflow를 유발해 500이 됨.
  문자·길이·패딩을 분리한 검증으로 교체. 인증 API 회귀는 RED500 → GREEN200.
- 저자가 추가 확인한 앱 종료 지연: onClose에서 프록시를 abort하면 서버의 요청 drain 이후라 늦음.
  preClose로 이동. 실제 HTTP 분석 중 종료 회귀는 RED timeout → GREEN. 독립 Worker 추론을 강제로 종료하지는 않음.

수정 후 타입/lint/build, Vitest69, Python14, Playwright6 및 실제 Node→Python HTTP smoke와 Linux Electron smoke 통과.
리뷰어 별도 검사: Worker 일반/encoded 경로 미인증401, Origin403, 잘못된 이미지422, 초과 본문413, 미설치503.

## 실행 중 결정과 비용

1. 반복된 사용자 시작 지시와 마스터 요구사항을 실행 승인으로 사용하고 설계/계획의 재승인 질문 없이 진행했다.
   설계가 기대와 다르면 후속 조정이 필요하다.
2. 전용 클라우드 체크아웃을 새 M3 브랜치로 사용했다. 의존성 복제를 피하지만 한 체크아웃에서 다른 브랜치를 동시에 편집할 수 없다.
3. 클라우드 스킬 일시 중단 중 보조 스크립트 대신 동일한 brief/ledger/test 증거를 직접 기록했다. 자동 ledger 형식 검사가 없다.
4. CPU 우선/로컬 모델 수동 준비를 선택했다. 검증되지 않은 GPU 메모리 경쟁을 피하지만 느리거나300초 제한에 걸릴 수 있다.
5. 실제 체크포인트 품질, 장시간 메모리, 전체300초 timeout 실측, Windows optional 추론/데스크톱 및 GPU는 별도 게이트로 남겼다.
   모의 결과는 추론 증거가 아니며 실기에서 호환성/성능 수정이 필요할 수 있다.

후속 실제 테스트/미검증 범위는 docs/QA_TEST_PLAN.md와 docs/IMAGE_TO_PROMPT.md를 따른다.
