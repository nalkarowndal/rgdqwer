# M6 Voice Studio design

Implements REQUIREMENTS.md §6 and M6: ko/ja/en Chatterbox Multilingual TTS, reference ChatterboxVC, trained RVC, profiles with permission information, long-text segmentation, microphone/upload, pitch, WAV/MP3, playback and comparison. RVC training remains a later milestone.

Use independently configured Python subprocesses, one per job, under the existing GenerationManager lock. Chatterbox and RVC have incompatible NumPy requirements; neither enters the analysis worker environment. Local models only, no automatic downloads. Subprocess termination releases the lock only after exit; restart marks interrupted local jobs failed without resubmission. ComfyUI external queues are checked before voice GPU work when reachable; disconnected ComfyUI does not block independent voice work. External GPU processes cannot be controlled by this application.

Profiles store reference UUID, name, languages, allowed engines, RVC catalog ID/path, preferred settings, permission text and attestation time. Each generation requires affirmative authorized-use confirmation. Delete/revoke profiles without erasing historical job snapshots; referenced audio cannot be deleted. No claims that attestation proves legal permission. Preserve Chatterbox's built-in watermark.

Audio uploads accept WAV, MP3, WebM/Opus only, maximum 16 MiB / 60 seconds / stereo / 48 kHz. FFmpeg forced demuxers, local protocol only, bounded decode to mono 24 kHz PCM WAV. Reference duration 3–30 seconds. TTS maximum 3000 characters, chunks <=180 Unicode code points; maximum output 600 seconds. Voice conversion source maximum 60 seconds. Output WAV and MP3 both validated and stored atomically; failed/cancelled jobs have no artifacts.

Engine configuration uses operator environment variables, never renderer-supplied paths/commands. RVC catalog is a local JSON manifest of trusted speaker models. RVC pickle-based upstream dependencies require trusted operator-provisioned assets; model upload/download is not exposed. Device is explicit cpu or cuda; no silent CPU fallback. Chatterbox pitch is unsupported and rejected; RVC supports -12..12 semitones. Chatterbox style supports exaggeration/CFG/temperature.

Electron allows microphone only from its own main frame and audio-only media request; camera and other permissions remain denied. Browser microphone streams stop on stop, error, navigation and unmount, including late permission responses. Recording auto-stops at 60 seconds and is bounded by upload limits.

Actual model inference, Windows microphone and 8GB GPU stability are acceptance gates, not inferred from mocks. This environment has no weights/GPU; Hugging Face is outside its allowlist. Implement and test orchestration with clearly identified fixture adapters; provide explicit real-model smoke instructions. M6 acceptance remains pending until genuine TTS and recorded voice conversion pass.
