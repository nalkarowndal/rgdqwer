# M3 Image to Prompt Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Native implementation, one fresh final reviewer.

**Goal:** 로컬 이미지 분석을 편집 가능한 프롬프트로 만들어 기존 이미지 생성에 연결한다.
**Architecture:** 인증 Node proxy → 독립 CPU Worker/adapters; React 편집 초안 → M2 PromptDocument.
**Tech Stack:** Fastify/React/Zod, FastAPI/Pillow/NumPy, optional Transformers/PyTorch/ONNX Runtime.
**Spec:** docs/superpowers/specs/2026-10-22-m3-design.md

## Global Constraints
- 자동 모델 다운로드/원격 코드 실행 없음; CPU only, 단일 분석, 300초 proxy timeout.
- PNG/JPEG/WebP 단일 프레임, 5 MiB/16 MP/8192 한계; 인증 전에 본문 파싱하지 않음.
- 모델 파일 발견 ≠ 추론 검증. 캡션 신뢰도 수치 없음. 미분류/미확인은 그대로 노출.
- M2의 문자열 보존과 생성 API 계약 유지. 실제 GPU 검증은 별도 게이트.

## Review Focus
- 악성/손상/거대한 이미지와 Worker 직접 접근은 거부되어야 한다 (Task 1/2).
- 모델 shape/태그 CSV 불일치는 잘못된 태그를 반환하지 않아야 한다 (Task 1).
- 분석 중 수정/잠금 및 페이지 이동은 사용자 값을 보존해야 한다 (Task 3).
- timeout/실패 시 이전 결과 유지, 중복 분석은 거부되어야 한다 (Task 1/2/3).
- 새 모델/파일이 없는 첫 실행에서 준비 방법이 보이고 생성 성공으로 표시되지 않아야 한다 (Task 3).

**Files:** worker/analysis.py, worker/adapters.py, worker/security.py, worker/run.py, worker/app.py; worker/tests/test_analysis.py; requirements.
**Interfaces:** POST /analysis {image: base64, model: florence|wd14|both} → {caption,ocr,tags:[{name,score,category}],models:string[],width,height}; GET /analysis/status → {busy,models:[{id,available,reason}],device:'cpu'}.

- [ ] Implement bounded upload validation, lazy native local adapters, single lock, safe error mapping, token file CLI and docs.
