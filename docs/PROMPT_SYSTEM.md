# 프롬프트 시스템

현재: 프롬프트 및 Image to Prompt 카테고리의 단계 안내만 제공. 변환 기능 미구현.

M2는 규칙 템플릿부터 구현하고 선택형 로컬 LLM adapter는 분리한다.
일반 한국어 문장을 규칙만으로 완전히 번역했다고 표시하지 않는다.
지원되는 키워드 변환·태그 매핑과 번역되지 않은 원문을 구분하고 사용자 편집을 보존한다.

공통 모델 프로필은 promptStyle(tags/natural), negative 지원, 파라미터 범위,
자동 확장 담당자(app/workflow/none)를 가진다. Krea Prompt Enhancer와 앱 확장기를 중복 실행하지 않는다.

M3는 Florence-2/WD14 후보를 실기 검증하고 필드별 캡션·태그·confidence·locked를 제공한다.
잠긴 필드는 재분석 결과로 덮어쓰지 않는다. 분석 결과는 원본 프롬프트 복원이 아니라
이미지 기반 재구성임을 명시한다. 수정된 결과를 이미지/영상/Krea 입력으로 전달한다.
규칙 기반/모델 기반 결과, 자동/수동 변경 이력을 구분한다.
