# M2 Prompt Studio Implementation Plan

> REQUIRED SUB-SKILL: superpowers:executing-plans. Native implementation followed by one independent final review.

Goal: 한국어 키워드/상세 항목/전문가 편집을 실제 이미지 생성에 연결하고 재사용한다.
Spec: ../specs/2026-10-22-m2-design.md
Architecture: src/prompt.ts pure compiler/schema → shared PromptEditor → image / prompt studio.
Store version3 snapshots → authenticated API; existing job stores optional source document atomically with history.
Constraints: no new dependencies or model downloads; M1 API compatibility; offline; preserve manual text exactly.

## Review Focus

- Negation/unknown Korean must survive conversion intact.
- Mode/profile/page changes must not discard manual edits.
- Saved snapshot and generated text must agree; old M1 jobs still reusable.
- Stored records must survive restart/migration/failure, with bounded history and preset cap.
- Unsupported model capabilities must not be advertised as runnable.
