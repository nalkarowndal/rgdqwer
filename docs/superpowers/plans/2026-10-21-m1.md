# M1 Implementation Plan

> Use superpowers:executing-plans. Existing user authorization covers implementation.

Goal: 실제 ComfyUI에 연결 가능한 Text to Image와 저장/복구 경로.
Spec: ../specs/2026-10-21-m1-design.md
Constraints: M0 보존, loopback, GPU 동시 1건, batch 1, 실제 GPU 검증 별도.

1. server/generation/workflow.ts와 src/contracts.ts에 입력/프로필/작업 계약 정의.
   노드 JSON 매핑, 상한/seed/크기 실패 테스트 후 구현.
2. server/store.ts에 작업·결과 영속성 확장. 기존 settings DB 유지 및 재오픈 테스트.
3. server/generation/{client,manager}.ts에 실제 HTTP/WS, history, 안전 취소, PNG 저장.
   tests/generation.test.ts에서 모의 엔진 통합 검증.
4. 인증된 job/artifact API와 src/ImageStudio.tsx 이미지 폼/작업 기록/미리보기/저장/재사용.
   e2e/generation.spec.ts 사용자 흐름 검증. M0 회귀 테스트 갱신.
5. 독립 코드 리뷰, 발견 수정, 전체 타입·린트·API·Worker·브라우저·빌드 검사.
   README/API/DB/이미지/로드맵/QA/CHANGELOG를 실제 구현 기준으로 갱신하고 PR 생성.

Review focus: ambiguous submission does not duplicate; global cancel never invoked;
stale progress cannot affect another job; output path/content validation; shutdown/restart preserves ownership.
