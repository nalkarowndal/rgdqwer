# M2 프롬프트 스튜디오 설계

사용자의 계속 개발 지시에 따라 M1 위에 공통 프롬프트 편집/변환/저장을 추가한다.
실제 GPU/Windows Electron 검증 게이트는 계속 보류하며 모의 생성과 혼동하지 않는다.

## 범위와 선택

규칙 기반 편집기를 우선한다. 클라우드 번역은 오프라인 요구와 맞지 않으며,
로컬 LLM은 추가 모델/VRAM 검증이 필요하므로 선택형 후속 adapter로 남긴다.
M2는 현재 실행 가능한 이미지 SD1.5/SDXL/Illustrious에 연결한다.
영상/음성/Krea의 입력 인터페이스는 각 실행 단계에서 확장한다.

## 계약

PromptDocument: version=1, mode(simple/detailed/expert), style(auto/tags/natural), text,
fields(subject/appearance/clothing/expression/pose/background/style/composition/lighting/color),
negative, suggestNegative, editedPositive/editedNegative(nullable).
compilePrompt(document, profile)는 positive, negative, warnings, unresolved, style, engineVersion을 반환한다.
원문, 매핑 결과와 미지원 한국어를 분리한다. 쉼표/줄바꿈으로 분리한 정확한 사전 항목만 매핑하며
모르는 구절은 그대로 보존한다. 자유 문장을 부분 치환해 부정/수식 관계를 훼손하지 않는다.
태그 출력과 문장형 조합을 지원하지만 자연어 번역/LLM 결과라고 부르지 않는다.
전문가 원문은 공백/가중치/이스케이프까지 보존한다. 자동 생성 결과도 직접 편집할 수 있으며
모드·프로필·원문 변경이 수동 결과를 덮어쓰지 않는다. 명시적인 추천 재적용 버튼만 수정값을 지운다.

## UI 및 영속성

이미지와 프롬프트 스튜디오가 같은 PromptEditor를 사용한다. 부모 App에 두 초안을 따로 보존한다.
간편 모드는 기본이며 한국어 예시, 추천 키워드, 검색 자동완성 버튼을 제공한다.
상세 모드는 10개 항목을 제공한다. 전문가 모드는 최종 positive/negative 직접 편집이다.
지원하지 않는 LoRA/샘플러 선택은 추가하지 않는다. 원문 복사, 프리셋 저장/삭제, 기록 저장/재사용,
명시적인 이미지 스튜디오로 보내기를 제공한다. 복사 실패는 수동 복사 안내로 처리한다.

SQLite version3은 기존 데이터 보존 후 prompt_records 테이블을 추가한다.
프리셋 최대100개, 기록 최근100개. 저장한 문서/프로필/최종 결과/엔진 버전은 snapshot이다.
이미지 Job에는 optional promptDocument를 보존한다. 서버는 최종 prompt/negative와 문서의 결과가
일치하는지 검사한다. 최초 Job 저장과 프롬프트 기록 저장은 같은 DB mutate에 묶는다.
기존 M1 작업은 원문 전문가 문서로 복구한다. 재사용 시 저장된 최종 결과를 고정한다.
새 API도 기존 Bearer/Origin 보호를 적용하며 요청 상한은128KiB이다.

## 검증

정확한 한국어 매핑, 미지원/부정 구절 보존, 수동 편집/가중치 문법 보존, 출력 길이 제한,
DB v2→v3 이동·재오픈·삭제·용량, 인증과 잘못된 snapshot 거절, 실제 HTTP fixture로
한국어→최종prompt→ComfyUI graph→PNG→기록을 검증한다. 브라우저에서 모드/페이지 이동,
수정 보존, 프리셋 새로고침 복원과 생성 연결을 검사한다.

근거: React 공식 controlled textarea / state preservation 문서(Context7),
https://docs.comfy.org/built-in-nodes/ClipTextEncode (Exa 공식 문서 검색).
