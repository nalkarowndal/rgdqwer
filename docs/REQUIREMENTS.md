# ComfyUI 기반 통합 로컬 AI 스튜디오 개발 — 마스터 프롬프트

## 0. 개발 역할 및 핵심 지시

당신은 AI 애플리케이션 아키텍트, 풀스택 개발자, ComfyUI 통합 엔지니어, UI/UX 디자이너, AI 모델 최적화 엔지니어, QA 엔지니어 역할을 수행합니다.

이번 프로젝트의 목표는 **ComfyUI를 핵심 생성 엔진으로 사용하는 독립형 Windows 로컬 AI 스튜디오**를 개발하는 것입니다.

사용자가 복잡한 ComfyUI 노드를 직접 다루지 않아도 이미지, 영상, 음성 생성과 변환 작업을 수행할 수 있도록 합니다.

프로그램의 주요 특징은 다음과 같습니다.

1. 이미지·영상·음성 생성 및 변환 기능 통합
2. ComfyUI 기반 로컬 AI 실행
3. 독립적인 React 기반 UI/UX
4. 카테고리별 AI 프롬프트 자동 생성
5. 이미지 업로드를 통한 Image to Prompt
6. Krea 2 RAW·Turbo 전용 카테고리
7. 음성 클로닝 및 보이스 컨버전
8. 모델·LoRA·커스텀 노드 통합 관리
9. 선택형 확장 모델 다운로드
10. 저VRAM 환경 최적화
11. 작업 기록, 프리셋, 결과물 관리
12. 자동 QA 및 브라우저 시각 검수

모든 기능을 한 번에 구현하지 말고, 공통 시스템을 먼저 완성한 뒤 각 카테고리를 단계적으로 개발합니다.

기능을 추가하는 과정에서 기존 기능의 동작을 망가뜨리지 않아야 합니다.

기존 프로젝트 파일이 있다면 구조와 설정을 먼저 분석하고 활용합니다. 기존 프로젝트 이름은 임의로 변경하지 않습니다. 프로젝트가 존재하지 않는 경우에만 신규 프로젝트를 구성합니다.

## 1. 개발 환경 및 기술 스택

### 기본 환경

- 운영체제: Windows 10/11
- 주 개발 환경: Windows 데스크톱
- GPU: NVIDIA GeForce RTX 2060 SUPER
- VRAM: 8GB
- CUDA 기반 로컬 추론
- 인터넷 연결 없이 기본 생성 기능 실행 가능
- 모델 다운로드 및 선택적 외부 서비스 연동에만 인터넷 사용

### 권장 기술

| 구분 | 기술 |
|---|---|
| 프론트엔드 | React + TypeScript + Vite |
| UI | Tailwind CSS + 접근성 고려 컴포넌트 |
| 데스크톱 실행 | Electron |
| 앱 제어 백엔드 | Node.js |
| AI 생성 엔진 | ComfyUI |
| AI 보조 실행 엔진 | Python + FastAPI |
| 로컬 데이터베이스 | SQLite |
| 이미지 분석 | Florence-2, WD14, JoyCaption 등 |
| 음성 합성 | Chatterbox Multilingual |
| 음성 변환 | ChatterboxVC, RVC |
| 영상·오디오 처리 | FFmpeg |
| 프론트엔드 테스트 | Vitest, Playwright |
| Python 테스트 | pytest |

버전은 무조건 최신으로 설치하지 말고 안정성, 상호 호환성, 현재 하드웨어 지원 여부를 검증해 선택합니다.

ComfyUI와 Python 음성 엔진은 가능한 한 서로 독립적인 실행 환경을 사용하도록 구성합니다.

## 2. 시스템 아키텍처

프로그램은 다음 구조를 기본으로 합니다.

사용자 UI (React + Electron)
↓
Node.js 애플리케이션 제어 서버
↓
통합 작업 스케줄러 / 모델 관리자 / 프롬프트 엔진
↓
ComfyUI 생성 엔진 + Python 보조 AI Worker
↓
SQLite / 로컬 모델 저장소 / 결과물 라이브러리

### 구현 원칙

- ComfyUI 자체를 새로 구현하지 않습니다.
- ComfyUI 공식 서버 API를 활용합니다.
- ComfyUI가 지원하지 않는 기능만 별도의 Python Worker로 처리합니다.
- 기존 ComfyUI 설치를 연결하는 기능을 제공합니다.
- 프로그램 전용 ComfyUI 환경을 별도로 구성할 수도 있도록 합니다.
- 모델 경로 및 설치 경로를 사용자가 변경할 수 있어야 합니다.
- 워크플로는 API 형식 JSON으로 관리합니다.
- 모델 및 노드 간 의존성을 검증합니다.
- 작업 상태를 UI에서 실시간으로 확인할 수 있어야 합니다.
- 로컬 서비스는 기본적으로 127.0.0.1에 바인딩합니다.
- 이미지, 영상, 음성 결과물과 생성 설정을 함께 보관합니다.

공식 API v2 및 self-hosted API를 비교한 후 현재 프로젝트에 적합한 연동 방법을 선택합니다.

## 3. UI/UX 공통 설계

UI/UX는 현대적이고 간결한 데스크톱 제작 도구를 지향합니다.

다음 조건을 충족해야 합니다.

- 초보자도 기능을 쉽게 이해할 수 있을 것
- 카테고리 이동이 빠르고 직관적일 것
- 모든 설정에 한국어 설명과 툴팁이 있을 것
- 고급 설정은 필요할 때만 노출할 것
- 이미지·영상·음성 결과를 쉽게 비교할 수 있을 것
- 긴 작업의 진행 상황과 취소 여부를 확인할 수 있을 것
- 오류 발생 시 원인과 해결 방법을 안내할 것
- 화면 크기에 따라 레이아웃이 자연스럽게 조정될 것

### 메인 내비게이션

1. 홈 / 대시보드
2. 이미지 스튜디오
3. 영상 스튜디오
4. AI 음성 스튜디오
5. Krea 2 스튜디오
6. 프롬프트 스튜디오
7. Image to Prompt
8. 모델·확장 관리자
9. 작업 기록 / 라이브러리
10. 설정

### 프롬프트 입력 모드

모든 생성 카테고리에는 다음 세 가지 입력 모드를 제공해야 합니다.

**간편 모드**

기본 모드입니다.

사용자가 한국어로 원하는 결과를 작성하면 해당 모델이 이해하기 적합한 프롬프트로 변환합니다.

추천 키워드, 예시 문장, 자동완성 기능을 제공합니다.

**상세 모드**

캐릭터, 외형, 의상, 표정, 자세, 배경, 조명, 구도, 동작 등을 개별 입력 영역에서 설정할 수 있습니다.

**전문가 모드**

프롬프트 원문, Negative Prompt, LoRA, 시드, 샘플러, 스텝 등 모델별 고급 옵션을 직접 편집할 수 있습니다.

단, 지원되지 않는 매개변수는 노출하지 않거나 비활성화해야 합니다.

## 6. AI 음성 스튜디오

AI 음성 기능은 다음 두 가지 방식을 모두 지원합니다.

### A. Text to Speech / Voice Cloning

텍스트를 입력한 뒤 참고 음성 프로필을 선택해 해당 음색을 참고한 음성을 생성합니다.

초기 엔진은 Chatterbox Multilingual 계열로 구성합니다.

필수 기능:

- 텍스트 입력
- 한국어·일본어·영어 음성 생성
- 참고 음성 등록
- 음성 프로필 선택
- 엔진이 지원하는 감정·발화 스타일 조정
- 긴 대사 자동 분할
- WAV / MP3 저장
- 음성 미리 듣기
- 여러 생성 결과 비교

### B. Voice Conversion

사용자가 녹음한 음성 또는 업로드한 음성을 목표 음색으로 변환합니다.

엔진:

- ChatterboxVC: 참고 음성 기반 즉시 변환
- RVC: 학습된 화자 모델 기반 변환

필수 기능:

- 음성 파일 업로드
- 마이크 녹음
- 참고 음성 선택
- RVC 모델 선택
- 피치 조정
- 음성 변환
- 전후 비교
- 결과 저장

### 음성 프로필

하나의 프로필에서 다음 데이터를 관리합니다.

- 프로필 이름
- 참고 음성 파일
- 지원 언어
- 사용 가능한 TTS 모델
- 사용 가능한 VC 모델
- 학습된 RVC 모델 경로
- 자주 사용하는 설정
- 사용 권한 정보

허가받지 않은 실존 인물의 목소리를 사칭하거나 비동의 복제·배포하는 용도로 사용되지 않도록 필요한 안내 및 통제를 구현합니다.

### RVC 모델 학습

RVC 신규 모델 학습 기능도 개발 범위에 포함하지만, 초기 TTS·VC 기본 기능이 안정화된 이후 구현합니다.

전처리, 특징 추출, 피치 추출, 학습 진행률, 체크포인트 관리, 인덱스 생성, 모델 검증을 지원하도록 설계합니다.

## 7. Krea 2 전용 스튜디오

Krea 2를 일반 이미지 생성 메뉴와 별도의 독립 카테고리로 제공합니다.

### 지원 모델

- Krea 2 Turbo
- Krea 2 RAW

Krea 2 Turbo는 빠른 이미지 생성에, RAW는 기반 모델 활용과 LoRA 학습 등에 적합한 것으로 구분합니다.

공식 권장 설정과 실제 ComfyUI 워크플로를 확인해 모델별 기본값을 제공합니다.

### Krea 2 전용 기능

- 간편 자연어 입력
- 한국어 프롬프트 작성
- 영어 프롬프트 변환
- 프롬프트 자동 확장
- RAW/Turbo 전환
- Krea 호환 LoRA 관리
- 스타일 프리셋
- 이미지 비율·해상도 선택
- Image to Prompt 연동
- 결과 미리보기 및 저장

공식 ComfyUI 워크플로의 Prompt Enhancer와 앱 자체 프롬프트 생성기가 중복으로 작동하지 않도록 제어합니다.

### 하드웨어 제약

Krea 2는 높은 메모리를 요구하는 모델입니다.

RTX 2060 SUPER 8GB에서 정상적인 속도와 안정성을 보장할 수 없으므로 다음과 같이 구현합니다.

- 모델 설치 전 VRAM 및 시스템 RAM 확인
- 현재 환경에서 실행 가능한지 검사
- 지원 가능한 저VRAM 실행 방식 탐색
- 호환되지 않으면 구체적인 이유 안내
- 기본 이미지 생성 기능은 Krea 2와 관계없이 정상 작동해야 함
- Krea 2를 필수 설치 모델로 강제하지 않음

공식 라이선스와 모델 사용 조건을 준수합니다.

- 외모
- 의상
- 표정

- 배경
- 화풍
- 구도
- 조명
- 색감
- LoRA

태그형 및 자연어형 프롬프트 출력을 모두 지원합니다.

### 영상 프롬프트 생성기

입력 영역:

- 주체

- 동작 속도
- 카메라 이동
- 배경 변화

TTS는 대사, 언어, 화자, 발화 스타일을 중심으로 구성합니다.

RVC는 자연어 프롬프트보다 변환 옵션이 핵심이므로 별도의 설정 생성 UI를 사용합니다.

### 공통 기능

- 한국어 입력
- 모델별 프롬프트 변환
- 자동완성
- 추천 키워드
- 프리셋
- 프롬프트 개선
- 프롬프트 복사
- 생성 기록
- 재사용

## 11. 저VRAM 최적화

RTX 2060 SUPER 8GB를 기준으로 다음 기능을 구현합니다.

- VRAM 자동 감지
- 시스템 RAM 확인
- 사용 가능한 CUDA 환경 검증
- 모델별 예상 메모리 요구량 표시
- GPU 모델 동시 실행 제한
- 생성 전 메모리 확보
- 사용하지 않는 모델 언로드
- CPU 오프로딩
- 배치 크기 자동 조정
- 영상 해상도 및 길이 제한
- 음성 긴 문장 분할 처리
- OOM 발생 시 오류 복구

모든 모델이 8GB에서 실행된다고 가정하지 않습니다.

실행 가능 여부가 불확실한 모델은 반드시 실기 테스트로 검증합니다.

GPU 메모리 확보 실패가 전체 프로그램 종료로 이어지지 않도록 프로세스를 격리합니다.

12. 기존에 정상 작동하던 기능을 유지합니다.
13. 불필요한 외부 API 및 유료 서비스 의존성을 만들지 않습니다.
14. 진행 상황과 미완료 항목을 명확하게 보고합니다.
