# 프로젝트 개요

## 목적

ComfyUI 노드를 직접 다루지 않아도 이미지·영상·음성을 생성하는 Windows 제작 도구.
RTX 2060 SUPER 8GB를 기준으로 하되, 모델별 실행 가능성을 별도 검증한다.
이름은 기존 저장소 rgdqwer를 유지했다.

## 초기 조사

- 원격 저장소: 커밋/파일이 없는 빈 저장소. 보존할 기존 코드, AGENTS.md, 설정 없음.
- 작업 환경: Linux, Node 24.19.0, Python 3.12.14. 사용자 Windows PC에 접근한 것이 아님.
- ComfyUI, 학습 모델, RTX 2060 SUPER 실기는 제공되지 않음.
- 개발 범위: 사용자 마스터 프롬프트에 따라 M0 실행 기반 이후 M1 이미지 생성, M2 프롬프트, M3 이미지 분석, M4 Krea 2, M5 영상 구현으로 진행.

## 실제 구현

React/Electron, Node HTTP 서버, SQLite 설정·작업·결과 저장, ComfyUI 연결/기본 T2I 실행,
PNG 미리보기·다운로드·설정 재사용, 안전 취소·재시작 추적, 3모드 프롬프트·규칙 매핑·프리셋/기록 저장, Python 진단/선택형 CPU 이미지 분석 Worker, 필드 편집·잠금·생성 연결과 자동 검사. Krea RAW/Turbo·LoRA, Wan T2V/I2V/실험적 V2V 그래프와 FFmpeg 실제 변환·보간·프레임 추출·MP4 재생도 구현했다.

## 미구현

M1 실제 모델/GPU 검증 및 Anima 전용 그래프, M3 실제 분석 품질 검증, M4/M5 실제 모델·GPU 검증, M6–M8 음성/모델 관리/배포 및 선택형 로컬 LLM.
카테고리 페이지의 존재가 해당 기능의 구현 완료를 의미하지 않는다.
실제 모델 검증과 CPU 미디어 변환 검증을 구분한다. M5의 실제 FFmpeg 변환·재생은 통과했고 Wan 추론은 보류다.
