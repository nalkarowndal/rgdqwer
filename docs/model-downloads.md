# 기능별 모델 다운로드: 속도와 연결 중단

`모델·확장 관리자 → 기능별 다운로드`에서 기능을 선택하면 필요한 구성 파일을 받습니다. 4 MiB 이상의 파일은 서버가 HTTP Range를 지원할 때 최대 4개 연결로 나눠 받습니다. 서버가 지원하지 않으면 일반 다운로드로 전환합니다. 실제 속도는 모델 제공자, 회선, 저장장치 상태에 따라 달라집니다.

연결이 일시적으로 끊기면 구간별로 최대 3회 시도합니다. 이미 받은 구간은 같은 작업에서 유지하고 실패한 구간만 다시 받습니다. 일반 다운로드도 서버가 지원하면 받은 위치부터 이어받습니다. 임시 CDN 주소가 만료되면 원래 모델 주소에서 새 주소를 받습니다. 연결이 120초 동안 응답하지 않을 때 재시도하며, 전체 파일 다운로드 시간에는 이 제한을 적용하지 않습니다.

화면의 진행률은 메모리에서 갱신하고 디스크의 진행 기록은 5초 간격으로 저장하여 잦은 데이터베이스 저장 부담을 줄였습니다. 병렬 구간은 파일 순서대로 검증·저장하므로 진행률이 잠시 멈춘 뒤 한 번에 늘어날 수 있습니다.

계속 실패하면 `aborted` 대신 연결 상태 확인과 재시도를 안내합니다. **취소하거나 앱을 종료하면 현재 파일의 미완성 데이터는 삭제됩니다.** 다시 기능별 다운로드를 누르면 완료·검증된 구성 파일은 재사용하고 미완성 파일부터 다시 받습니다. 앱 재시작 후 미완성 파일의 바이트 단위 이어받기는 지원하지 않습니다.

서버가 이어받기를 거부하면 잘못된 파일을 만들지 않고 중단합니다. 재시도하거나 브라우저에서 받은 파일을 가져오세요. 잘못된 범위·크기·SHA256, 기존 파일 충돌, 디스크 공간 부족은 연결 재시도로 숨기지 않습니다.
