설정·기록·가져온 모델: %APPDATA%\rgdqwer\studio
설치형과 ZIP 실행형은 같은 Windows 계정에서 같은 데이터를 사용합니다.
앱 폴더를 다른 위치로 옮겨도 기존 데이터는 위 경로에 남습니다.
USB로 앱 폴더를 복사해도 데이터와 외부 엔진은 자동으로 따라가지 않습니다.
업데이트: 앱을 종료하고 새 ZIP을 별도 폴더에 모두 풀어 실행하세요.
백업: 앱을 완전히 종료한 뒤 %APPDATA%\rgdqwer 전체와 별도 모델 폴더를 복사하세요.

Node.js는 앱 실행에 필요하지 않습니다.

설치와 기능별 준비 안내: resources\docs\INSTALLATION.md
