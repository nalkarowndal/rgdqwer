# M4 Krea 2 스튜디오

기존 Windows Electron/React/TypeScript/Fastify 앱에 선택형 로컬 Krea 2 T2I를 추가한다. 사용자 마스터 요구사항 §7/M4와 반복된 시작 지시에 따라 기존 기술과 단계별 구현 방식을 유지한다. 아래 세부 선택은 구현자의 판단이다.

## 접근 방식
- 채택: 공식 ComfyUI Turbo 템플릿을 평탄화한 API 그래프와 RAW 어댑터를 기존 단일 GenerationManager에 연결. 취소·복구·PNG 무결성·기록을 공유한다.
- 별도 Python Krea 엔진은 설치/메모리 소유권이 중복되므로 제외.
- 임의 워크플로 업로드는 입력/출력 소유권 검증 범위를 넘으므로 제외.

## 계약
- 기존 ImageInput은 유지하고 GenerationInput = ImageInput | KreaInput. Krea 입력은 profile=krea-turbo|krea-raw, checkpoint(UNET), textEncoder, vae, prompt, sourcePrompt, enhancer=none|app|engine, negative='', width,height,seed,steps,cfg,lora(null 또는 name,strength,trigger). 공통 작업 kind=image 유지, workflowVersion=krea2-v1. Krea 기록은 job JSON에 저장하며 SD 전용 prompt_records에는 넣지 않는다.
- Turbo 공식 템플릿: UNETLoader(default), CLIPLoader(type=krea2,device=default), VAELoader, EmptyLatentImage, CLIPTextEncode, ConditioningZeroOut, KSampler(euler/simple,8,CFG1), VAEDecode, SaveImage(id9). 엔진 기본 shift=1.15.
- RAW:52스텝, Comfy CFG4.5. 공식 standalone은 cond+3.5*(cond-uncond), Comfy는 uncond+4.5*(cond-uncond)이므로 수학적으로 대응. 빈 문자열 CLIP negative. ModelSamplingFlux의 base/max_shift를 같은 값 mu=.5+.65*(width*height/256-256)/(6400-256)로 고정해 공식 RAW 256~1280 해상도 기반 shift를 재현. RAW는 어댑터이며 공식 Turbo 템플릿 그대로라는 주장을 하지 않는다. 실제 추론 검증 전.
- 해상도 64배수, 최소512, Turbo 최대2048, RAW 최대1024, 최소 한 변1024. 배치1. 검증된 단일 그래프만 생성한다.
- LoRA 로컬 목록과 공식 9종 스타일/트리거/강도1 제공. 임의 로컬 Krea LoRA는 사용자가 모델 카드를 확인해 선택. 파일명은 호환성 증거가 아니다. 다운로드/삭제/학습은 M7 이후.
- 자연어 한국어 입력. app 모드는 기존 M2 사전 기반 정리(전체 번역 아님), none은 입력 그대로, engine은 공식 TextGenerate(Qwen3VL)로 영어 확장. enum으로 중복 확장 방지. 최종 입력 편집, source 보존. engine은 생성 시 확장하므로 화면 미리보기는 확장 전 입력임을 명시. 공식 프롬프트 지침을 보존하고 영어 출력 요구만 추가. LoRA 트리거는 확장 후 결합.
- 필수 노드/콤보/실제 로컬 모델 목록을 /object_info로 검사하고 제출 전 재검사. 누락 시 정확한 이유로 제출 차단. GPU/VRAM/RAM은 /system_stats에서 보고, 없거나 적으면 미검증 경고. 파일 크기는 VRAM 요구량이 아니다. 8GB 보장/실행 불가 단정 금지. --lowvram, CPU text encoder/offload는 안내만 제공하고 기존 엔진 설정을 바꾸지 않는다.
- 라이선스 원문 링크와 $1M 매출 기준 및 필터/검토 의무 안내. 모델·라이선스 동의 대행이나 가중치 배포 없음. 결과는 사용자가 검토 후 수동 다운로드.
- Image to Prompt에서 편집한 결과를 Krea에 적용, enhancer=none로 보내 중복 확장 방지. SD와 Krea 화면·기록 재사용 목적지를 구분하고 한 GPU 작업 잠금은 공유한다.

## 검증과 한계
공식 소스 노드 계약을 근거로 단위/HTTP/브라우저 테스트. 가짜 엔진은 합성 흰 PNG만 내며 모델 추론 성공 증거가 아니다. 실제 모델/GPU/Windows 데스크톱 실행, 특히2060SUPER8GB는 수동 게이트. CPU-only 환경도 테스트 제출을 허용하되 적합성 보장 없음.
